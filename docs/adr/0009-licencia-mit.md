# ADR 0009: Licencia MIT

- **Estado:** Aceptada
- **Fecha:** 2026-11-18

## Contexto

Un repo público sin licencia no da permiso legal de reutilizar nada, aunque cualquiera pueda verlo.

## Decisión

Publicar con licencia MIT.

## Consecuencias

- Cualquiera puede usar, modificar y compartir el código, incluso de forma comercial, siempre que conserve el aviso de copyright.
- El software se entrega sin garantía.
- La licencia cubre todo el repo, incluido el contenido de `data/` (el plan personal). Si eso deja de ser deseable, se puede licenciar solo el código.

## Alternativas consideradas

- **Sin licencia:** todos los derechos reservados; nadie puede reutilizar nada.
- **MIT para el código y otra licencia (o ninguna) para `data/`:** más preciso, pero más complejo de explicar.
