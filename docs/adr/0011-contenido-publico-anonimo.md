# ADR 0011: No publicar datos internos del trabajo

- **Estado:** Aceptada
- **Fecha:** 2026-11-18

## Contexto

El repo es público y la página lleva el nombre del autor. Algunos documentos originales mencionaban la empresa actual y sus sistemas.

## Decisión

- No nombrar a la empresa ni sus sistemas en el contenido público ("Usa tu trabajo como laboratorio", "Migración del sistema").
- Los proyectos de portafolio se escriben desde cero; nunca se sube código ni datos del trabajo.

## Consecuencias

- Se puede compartir el link sin exponer información de la empresa.
- El plan menciona metas de sueldo y cambio de trabajo. Es una decisión consciente del autor; si cambia, se puede mover esa parte a un repo privado.

## Alternativas consideradas

- **Repo privado:** protege todo, pero GitHub Pages en cuentas gratuitas necesita repo público.
